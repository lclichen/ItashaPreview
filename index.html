可编辑区域

先为每个视角生成遮罩，再贴图。遮罩决定立绘 / 拉花能显示在车的哪些部位。

遮罩工具

左键操作，按住 Alt 反向（魔棒/画笔均可）。车窗、车顶缝隙易被误选：用「魔棒排除」点一下即可剔除。完成后点「完成」返回。

AI 抠图 remove.bg

API Key（每月 50 次免费，仅存本地浏览器）
在 remove.bg 免费注册获取 Key 后填入。选中图层后点「AI 抠图」去除背景。
